# 🏠 Task 3 – Multimodal Machine Learning (Housing Price Prediction)

## 📖 Objective
Predict housing prices using both:
- Structured tabular data (bedrooms, bathrooms, sqft, etc.)
- House images

This project implements multimodal learning by combining CNN-based image features with tabular features.

## 🧠 Model Architecture

1. **Tabular Pipeline**
   - Missing value handling
   - One-hot encoding
   - Feature scaling

2. **Image Feature Extraction**
   - Pretrained CNN (ResNet18)
   - Final layer removed
   - Extract deep image embeddings

3. **Feature Fusion**
   - Concatenate tabular + image features
   - Feed into regression model

4. **Regression Model**
   - Feedforward Neural Network

## 📊 Evaluation Metrics
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)

## 🔥 Key Skills Demonstrated
- Multimodal learning
- CNN feature extraction
- Feature fusion
- End-to-end ML pipeline
- Model saving & reproducibility
