## 📌 Task 1: Exploring and Visualizing the Iris Dataset

---

## 🎯 Objective
The objective of this task is to **load, explore, and visualize the Iris dataset** in order to understand data distributions, relationships between features, and patterns among different flower species. This task focuses on data exploration and visualization fundamentals in machine learning.

---

## 📊 Dataset
- **Name:** Iris Dataset  
- **Source:** Loaded directly using the `seaborn` library  

### Dataset Description
- Total Samples: **150**
- Total Features: **5**
  - Sepal Length
  - Sepal Width
  - Petal Length
  - Petal Width
  - Species

---

## 🛠️ Tools & Technologies Used
- **Python**
- **Pandas** – Data loading and inspection  
- **Matplotlib & Seaborn** – Data visualization  
- **Jupyter Notebook** – Implementation and analysis  

---

## 📈 Data Visualization Techniques
- **Scatter Plots** – To observe relationships between features  
- **Histograms** – To analyze feature distributions  
- **Box Plots** – To identify outliers and spread of data  

---

## 🧠 Key Results & Findings
- The dataset contains **150 rows and 5 columns**.
- Clear clusters are visible in scatter plots, particularly for the **Setosa** species.
- **Petal length and petal width** are strong indicators for distinguishing species.
- Box plots revealed **minor outliers** in the sepal width feature.
